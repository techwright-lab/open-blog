# Open Blog agent instructions

Start with `README.md` for the Rails engine, public contracts, tests, and releases.
The repository is `open-blog`; the gem and canonical vault slug are `open_blog`.

## Product documentation

Canonical product plans, decisions, and operating notes live in
`../_vault/products/open_blog/docs/`. Before creating durable notes, read
`../_vault/organization/policies/product-documentation-placement.md`.
The existing repository `docs/` serves the public documentation site; keep
internal agent configuration, glossaries, ADRs, plans, and audits in the vault.

## Agent skills

### Issue tracker

Track work in Paperclip (TechWright Labs, TEC), not GitHub Issues.
Before tracker operations, read `../_vault/products/open_blog/docs/agents/issue-tracker.md`.

### Triage labels

Use the five default triage labels.
Before triage, read `../_vault/products/open_blog/docs/agents/triage-labels.md`.

### Domain docs

Single-context glossary and ADRs live in the vault.
Before exploring code, read `../_vault/products/open_blog/docs/agents/domain.md`.
