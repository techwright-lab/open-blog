# Configuration

Edit `config/initializers/open_blog.rb` in your host application. Required settings are checked at boot. The initializer generated by `open_blog:install` contains the available defaults.

```ruby
OpenBlog.configure do |config|
  config.site_name = "My Journal"
  config.public_base_url = "https://example.com"
  config.default_author = { name: "Example Author", type: :person }
  config.publisher = { name: "My Company", url: "https://example.com" }
end
```

Required configuration is checked at application boot. The copied templates live in the host's `app/views/open_blog` and call gem helpers for metadata, structured data, dates, and notices. Customize those views and `app/views/layouts/open_blog.html.erb` in your application.

## Runtime settings

| Setting | Purpose |
| --- | --- |
| `public_base_url` | Public origin used for canonical URLs, sitemaps, previews, and fetched reports. |
| `default_author`, `publisher` | The default writing identity and responsible publisher. Replace sample values. |
| `authenticate` | Optional host authentication callback returning an actor with a name and optional scopes and ID. |
| `parent_controller` | Host controller inherited by reader controllers. |
| `color_scheme`, `syntax_theme` | Reader theme and code highlighting. |
| `feed_size`, `feed_content` | Feed size and summary or full content. |
| `primary_list_type`, `serve_sitemap` | Categories or tags for primary lists, and whether the engine serves its sitemap. |
| `preview_expires_in` | Preview lifetime, seven days by default. Changing it invalidates existing links. |
| `search_rate_limit` | HTML and JSON search allowance per address, 30 per minute by default. |
| `policy_urls` | Existing host policy URLs that override gem-hosted policy pages. |
| `mcp.enabled`, `mcp.max_page_size` | MCP availability and its maximum result page size (50 by default). |
| `page_views`, `page_view_retention_days`, `popular_posts` | Counting, retention, and the popular-article sidebar. |
| `image_fetch_policy`, `image_delivery` | External image fetching and stable image delivery. |

Use a shared cache store when running multiple application processes so actor rate limits are shared. Scheduled publishing needs a durable Active Job adapter or the recurring `open_blog:publish_due` task.
